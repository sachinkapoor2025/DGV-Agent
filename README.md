# DGV AI Business Operating System

AI COO for **Divit Global Ventures** managing:

1. UsaRakhi  
2. Blossompot  
3. SpicyCenter  
4. HalloweenReady  

## Stack

Next.js 16 · TypeScript · Tailwind · Drizzle · SQLite · Zod · GitHub Actions

## Quick start

```bash
npm install
npm run seed
npm run dev
```

Open http://localhost:3000 → login as `divit@dgv.local` / `dgv-admin-change-me`.

## What works today

- Central AI COO briefings + risk/capacity/decision queue
- Four growth agents that create scored, outcome-based tasks
- Dashboard, task board, team capacity, reports, integrations status
- Cron APIs for morning / midday / evening / weekly automation
- Cookie auth + audit log + approval-gated decisions
- Single CI pipeline: `.github/workflows/ci.yml`
